# SUElections-FE

### About SUElections

#### This project is meant to be a useful tool for organising elections to the Student's Council or running a referendum on issues important for a school community


### Frontend config

#### Install packages


```
npm i
```

##### Remember to run [backend](https://github.com/michalbojdo/SUElections-BE) 

#### Run application

```
npm run dev
```
